# Copy-paste ranking update prompts

Open one file, copy its entire contents into a separate agent conversation, and send it. Alternatively attach the `.txt` and say: “Read the full attached request and carry out the ranking update.” Each file includes the complete current ranking, all current source records with URLs and saved evidence notes, and tailored instructions to return enhanced rankings with stronger sourcing.

These are exports from the existing database, not newly researched updates. All 66 researched rankings are included; start with the 14 priority targets below. No database records were changed. The largest files are better attached than pasted.

The detailed snapshots and expanded instructions are also retained in the parent folder.
