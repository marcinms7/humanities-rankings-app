IMPORTANT INTERPRETATION
The initial app is an editorially designed, translation-based self-study syllabus. The proposed expansion is informed by the breadth of Classics degrees. Neither is an accredited degree, an official university curriculum, or a claim that completing a list of books is equivalent to university study.

The original user chose balanced foundations across literature, history, philosophy and rhetoric, with English translations as the default. The expanded catalogue should also include languages and the other principal components of Classics: art, archaeology, religion, society, institutions, evidence, textual scholarship and reception.

The user explicitly required private hosting and no public release without approval. Preserve that instruction when reusing this specification. Saving this handoff does not authorise changing a site’s audience, enrolling in courses, or publishing user notes.

This is a content and product handoff. It does not contain the application source code, credentials, private browser notes or the user’s actual reading-completion state. Do not infer that any reading has been completed. The live website has not been updated as part of producing this file.

A. EXISTING APPLICATION [IMPLEMENTED V1]

A1. Identity and purpose
Name: Paideia — A classical education.
Deployed URL: https://paideia-classical-notebook.marcinswier01.chatgpt.site
Last confirmed deployment in this conversation: version 1; deployment succeeded.
Last confirmed access policy in this conversation: owner-only; one allowed account, no groups and no external visitors. This is a historical verification, not a fresh access check performed while writing this file.
Purpose: help an independent learner choose a reading path through Greek and Roman texts and later reception, understand useful preparation, read assigned passages, reflect, and retain notes and progress.

A2. Visual design
A restrained notebook/library aesthetic: warm off-white pages, sage and olive accents, serif display headings, simple sans-serif interface labels, and an original architectural arch illustration. The desktop interface has a left navigation sidebar and a main content area. On smaller screens, navigation moves to the top and content adapts to the available width.
Main heading: “A classical education. A path of your own.”
Main action: begin with Homer, or continue to the next recommended unfinished module.
The interface identifies itself as a private study space and says that notes and progress remain in the browser.

A3. Three principal views
1. Syllabus: grouped module cards, search, filters, workload and progress.
2. Reading order: the numbered sequence with clickable prerequisite links.
3. Course options: a separate directory of external organised courses.
A Sources & approach dialog describes the editorial method and lists resources. TXT export is available from the sidebar and footer, including on mobile.

A4. Syllabus controls
Study path: Lighter or Rigorous.
Both paths contain the same 24 modules; switching changes reading scope, written work, estimated hours and displayed completion.
Subject filter: All subjects, Literature, History, Philosophy, Rhetoric, Reception.
Period filter: All periods or a period represented in the module records. A module can belong to more than one period.
Progress filter: All progress, Ready to read, Not completed, Completed.
Search: case-insensitive and accent-insensitive matching across titles, authors, subtitles, rationale, reading assignments, subjects and periods.
Filters combine with AND logic. Clearing filters restores the full catalogue. A no-results state provides recovery.
The numbered sequence remains unchanged when filtered; it is not renumbered into a new curriculum.

A5. Period semantics
Existing period labels are: Archaic Greece; Classical Greece; Hellenistic world; Roman Republic; Roman Empire; Late antiquity; Medieval reception; Early modern reception; Modern reception.
The period field broadly describes worlds studied and can include multiple categories. The separate era field records composition dates or explicitly distinguishes events from authors. Some modules deliberately cross periods: for example, Epicurus and Lucretius cross Greek and Roman contexts, while Arrian is a later source for Alexander.
Do not assume a text’s subject date is its composition date. The proposed model below separates these dimensions more explicitly.

A6. Prerequisites and continuation
Prerequisites are recommended preparation, not locked access or formal university requirements.
A module is “Ready to read” if it is unfinished and every listed prerequisite is complete on the active path.
The main continuation action selects the earliest unfinished ready module; if there is none, it selects the earliest unfinished module. When all modules are complete, the action becomes a review option.
A module’s detail dialog shows prerequisite links and reverse links to modules for which it is preparation. Previous/next controls follow the complete original sequence.

A7. Module detail content
Each module has a stable ID, title, author or authors, subtitle, subject tags, period labels, date/context, original-language description, rationale, exact lighter reading assignment, exact rigorous assignment, two hour estimates, supporting study, a study question, written work and resource links.
The lighter task is normally a 150–250-word response using two passages and recording one uncertainty.
The rigorous task is the module-specific essay, comparison, annotation or other activity in the records below.
The detail dialog also contains editable notes and a reversible completion control.

A8. Progress and notes
Completion is stored separately for Lighter and Rigorous. Completing one does not automatically complete the other.
Notes are shared between the two paths for the same module.
Notes save as the user types, using browser localStorage. The current storage key is paideia-study-v1. Notes have a 20,000-character input limit per module.
The browser record contains path, pace, complete.light, complete.rigorous and notes keyed by module ID. It stores no server-side learning profile.
Path, weekly pace, completion and notes persist locally. Current view, filters and search do not persist across a reload.
Browser data is not automatically synced between devices or browsers. Clearing browser storage can remove it. The initial app offers a TXT export but no import/restore interface.
No reading is pre-marked complete, and no personal note content is included in this handoff.

A9. Workload
Lighter path total: approximately 178 hours.
Rigorous path total: approximately 604 hours.
These are editorial planning estimates including the specified study activities. They exclude complete optional courses and sustained language study.
Weekly pace options: 3, 4, 6 or 8 hours. Default: 4 hours.
Displayed total weeks = ceiling(total estimated path hours / selected weekly hours). It is a total-programme estimate; it is not recalculated as a remaining-time estimate after completion.
At 4 hours/week: approximately 45 weeks for Lighter and 151 weeks for Rigorous.
At 8 hours/week: approximately 23 weeks for Lighter and 76 weeks for Rigorous.
The 604-hour figure belongs only to the initial reading programme. It must not be reused as an estimate for the expanded degree-informed curriculum.

A10. Export
The existing TXT export includes all 24 modules, both reading scopes, workload estimates, both completion states, notes from that browser, questions, supporting study, prerequisites, resource URLs, course descriptions and resource notes.
This handoff is broader: it contains the existing content and the proposed expansion, but has no access to the user’s browser notes or progress.

A11. Technical and privacy characteristics
The initial app is a static, dependency-free application written in HTML, CSS and JavaScript. Its static deployment directory is dist. There is no application backend, analytics, external font request, third-party JavaScript or embedded course material.
External resources open as links. Institutional names identify sources and course providers; they do not imply endorsement.
Privacy is enforced by the hosting platform’s access policy. A noindex/nofollow tag is supplementary and is not an access-control mechanism.
Native HTML dialogs, keyboard focus styles, labelled controls, a skip link and reduced-motion styling are implemented. Responsive breakpoints are present at 1150, 930, 690 and 370 pixels.

A12. Validation actually completed
JavaScript syntax checks passed. All 24 IDs are unique; all prerequisite and resource references resolve; prerequisites form an acyclic graph and precede their dependants in the chosen order.
Fifty checks ran against actual application logic and generated markup in a minimal DOM harness. They covered search, combined filters, empty results, readiness, completion, separate paths, assignment and workload switching, prerequisites, notes, escaping, reading order, course separation, source listing, pace calculation, all detail views and export execution.
HTML parsing, unique HTML IDs and existence of referenced local scripts, stylesheets and icon were checked.
Deployment succeeded and owner-only access was confirmed.
Browser rendering and end-to-end interaction testing were not completed: the available browser runtime could not launch and an alternative download was unreachable. Do not describe the first release as visually tested or fully browser-tested.

A13. Scope limits
The initial version does not provide sustained Greek/Latin teaching, a full historical survey textbook, dedicated archaeology or art-history modules, structured source-methods training, external marking, multi-device persistence, a complete genre taxonomy, or the full expanded curriculum proposed below. Some supporting study is a direction to use an annotated edition rather than a fully assembled reading pack.

Status: IMPLEMENTED_V1
Reading-order number: 01
Title: The Iliad
Author(s): Homer
Subtitle: Anger, honour & the human cost of war
Stage: 1 — Epic & early voices
Period labels: Archaic Greece
Subject tags: Literature
Date/context: c. 8th–7th century BCE
Language description: Ancient Greek → English
Rationale: Begin with the epic vocabulary that tragedy, Roman epic and later writers repeatedly reshape. The poem concerns a short stretch of the Trojan War; it does not narrate the fall of Troy.
Recommended prerequisites: None

LIGHTER PATH
Estimated study hours: 12
Primary reading: Books 1, 6, 9, 16, 18, 22 and 24. Read a plot outline for the intervening books.
Practice: Write a 150–250-word response to the study question below. Anchor it in two passages and note one uncertainty to return to.

RIGOROUS PATH
Estimated study hours: 30
Primary reading: All 24 books. Compare one passage in two translations and keep a glossary of honour, excellence, fate and glory.
Written work: Write 800 words on honour and grief, using three short passages and noting who speaks.

SHARED STUDY MATERIAL
Supporting study: Before reading: locate Troy, Mycenae and the Aegean on an atlas. Read your edition’s introduction on oral poetry and watch Yale lectures 1–6 selectively for historical orientation. Myth is not a documentary record of the Bronze Age.
Study question: Does the encounter between Achilles and Priam change what the poem asks us to admire?
Prepares for: odyssey — The Odyssey; hesiod — Gods, work & lyric voices; herodotus — The Histories; tragedy — Justice on the tragic stage; aeneid — The Aeneid; walcott — Homer across the Atlantic

F. EXPANDED CURRICULUM [PROPOSED V2]

F0. Overall choice
Build “Classics: Greece, Rome and their Reception” as a broad curriculum with literature and philosophy, continuous ancient-language study, a historical framework, material culture and explicit training in interpreting evidence.
The existing 24 modules should remain accessible as an introductory route. They are the starting point for expansion, not the complete common core of a degree-informed programme.
The full catalogue should offer a common core, an extended survey and specialist options. The selections below are a proposed content catalogue: they are not all mandatory complete readings. Exact passage assignments, total module count, textbook choices, teaching hours and a final core/elective allocation remain to be specified for new material.
All proposed material must carry an explicit development status until its reading scopes and supporting resources are ready.

F1. ANCIENT GREEK
Purpose: progress from beginner knowledge to increasingly independent reading, including sensitivity to grammar, expression and interpretation.
Content: alphabet; pronunciation; word formation; morphology; syntax; core vocabulary; adapted passages; prose; verse; metre; dialect differences when relevant.
Proposed author progression: adapted readings, then Xenophon and Plato, followed by Homer and tragedy. This is a flexible progression, not a claim that all Xenophon or Plato is elementary.
Practice: regular retrieval, parsing, short translations, guided reading, comparison of interpretations and selected composition exercises.
Prose and poetry should have separate reading milestones. Homeric language and poetic syntax need preparation beyond an introductory Attic course.
Prerequisites: language readiness rather than only literary-module completion.
Existing connections: the Greek OpenLearn taster and Greek-text modules. The taster is not a complete language curriculum.
To be specified: main textbook, lesson sequence, graded readers, answer/feedback provision, pace and proficiency benchmarks.

F2. LATIN
Purpose: build a sustained route from elementary grammar to authentic prose and poetry.
Content: pronunciation; morphology; syntax; vocabulary; adapted readings; prose and verse translation; grammar review; metre; selected composition.
Proposed author progression: selections from Caesar, Cicero and Catullus, then Virgil, Ovid and historians. Passage difficulty should govern placement, rather than assuming an author’s whole corpus has one level.
Practice: short daily language work, prepared and unprepared translation at an appropriate level, passage commentary and regular review.
Existing connections: the Latin OpenLearn taster, Cicero, Virgil, Catullus/Ovid and Roman historians.
To be specified: textbook, grammatical syllabus, exercise bank, beginner readers, feedback method and workload.

F3. GREEK POETRY
Coverage: epic, didactic poetry, lyric, iambic poetry, choral poetry, pastoral and Hellenistic experimentation.
Selected catalogue:
- Homer: Iliad; Odyssey.
- Hesiod: Theogony; Works and Days.
- Sappho: selected fragments.
- Archilochus: selected fragments.
- Pindar: selected odes.
- Apollonius of Rhodes: Argonautica.
- Theocritus: selected Idylls.
- Callimachus: selected poetry.
Skills: oral tradition; narrator and speaker; genre; metre; performance setting; allusion; fragmentary survival and editorial reconstruction.
Existing connections: iliad, odyssey, hesiod. Apollonius and the other additions need new records or expanded units.
Reading strategy: substantial complete epic readings in the extended route; selected short poems, fragments and odes with commentary. Do not invent missing text or treat editorial supplements as securely surviving words.
To be specified: fragment numbering/edition, selected odes and poems, translation choices and scope by depth.

F4. ROMAN POETRY
Coverage: lyric, short personal poetry, epic, pastoral, didactic poetry, elegy, satire and epigram.
Selected catalogue:
- Catullus: selected poems.
- Virgil: Eclogues; Georgics; Aeneid.
- Horace: selected Odes and Satires.
- Propertius and Tibullus: selected elegies.
- Ovid: Amores; Metamorphoses; Fasti.
- Juvenal: selected Satires.
- Martial: selected Epigrams.
- Lucan: an advanced epic option, with exact scope to be assigned.
Skills: Greek models and Roman adaptation; metre; poetic persona; patronage; audience; erotic and political rhetoric; genre boundaries.
Existing connections: aeneid, ovid, and the Lucretius content in hellenistic. Lucretius should also be discoverable as Latin didactic poetry even though its principal module is philosophical.
Reading strategy: an extended route can retain complete Aeneid and Metamorphoses readings; substantial selections are appropriate for the other large corpora before specialist study.
To be specified: poem/book selections, terminology and an expanded order with prerequisites.

F5. DRAMA AND PERFORMANCE
Selected catalogue:
- Aeschylus: Oresteia.
- Sophocles: Oedipus Tyrannus; Antigone.
- Euripides: Medea; Bacchae.
- Aristophanes: Clouds; Lysistrata.
- Menander: Dyskolos.
- Plautus: Menaechmi.
- Terence: Adelphoe.
- Seneca: Thyestes.
Content beyond reading: theatrical festivals, choral performance, masks, space, audiences, tragedy and comedy as different forms, and Greek/Roman adaptation.
Practice: complete selected plays; read or perform a scene aloud; compare translations; analyse a staging choice; compare an ancient play and later adaptation.
Existing connections: tragedy, comedy and shakespeare. The initial version does not yet cover this full Greek and Roman dramatic range.
To be specified: which plays form the common core and which are options, performance resources and precise assignments.

F6. PROSE FICTION, DIALOGUE AND BIOGRAPHY
Selected catalogue:
- Longus: Daphnis and Chloe.
- Lucian: True Histories.
- Petronius: Satyricon.
- Apuleius: The Golden Ass.
- Plutarch: selected Lives.
- Suetonius: selected imperial biographies.
Purpose: give imaginative prose, satire, narrative, dialogue and biography their own place in the literary curriculum.
Skills: narrator reliability; literary persona; fictionality; genre; episodic construction; desire and identity; the distinction between biography and historiography.
Reading strategy: selected complete shorter works and a major prose narrative such as The Golden Ass; an explicit note on fragmentary survival for Satyricon. “Complete” must mean all surviving assigned text, not an invented reconstruction of lost parts.
Existing connections: Suetonius in empire and Plutarch in shakespeare; most of this literary strand is new.
To be specified: selected Lives and biographies, full/excerpt status, order and scholarly reading.

F7. ANCIENT PHILOSOPHY
Sequence: Presocratic fragments → Socrates and Plato → Aristotle → Epicureanism, Stoicism and scepticism → Plotinus and Augustine, with Boethius as a bridge into medieval thought.
Subfields: ethics; political philosophy; epistemology; metaphysics; logic; philosophy of nature; psychology/philosophy of mind; aesthetics.
Method: reconstruct arguments, define terms, distinguish a position from an objection to it, compare competing interpretations, and write reasoned responses using passages.
Existing connections: socrates, republic, aristotle, rhetoric, hellenistic, stoics and augustine.
The current programme is strongest in ethics and politics. The expanded strand adds much more work on knowledge, metaphysics, logic, nature, mind and scepticism.
A detailed proposed reading sequence appears in Section G.
To be specified: exact excerpts for the additional philosophical works, supporting scholarship, prerequisites and assessment scope.

F8. ESSAYS, LETTERS AND REFLECTIVE PROSE
Selected catalogue:
- Seneca: On the Shortness of Life; On Anger; selected Moral Letters.
- Plutarch: selected Moralia, including On Listening and On the Tranquillity of Mind.
- Cicero: On Friendship; On Duties.
- Pliny the Younger: selected Letters.
Purpose: cover reflective and argumentative prose, ethical discussion, social observation and the literary letter.
Classification: “essays” is a useful discovery label, but preserve ancient forms such as dialogue, treatise, consolation and letter. Moralia is a collection of varied works, not a single uniform essay.
Skills: audience; voice; public versus private presentation; argument; practical ethics; literary construction of the self.
Existing connections: Cicero’s On Duties and Seneca’s letters are already present; the broader selections are proposed.
To be specified: precise letters, full-versus-selected reading scope, editions and comparative tasks.

F9. RHETORIC AND LITERARY CRITICISM
Selected catalogue:
- Lysias: selected speeches.
- Demosthenes: selected speeches.
- Cicero: Catilinarian speeches; On the Orator.
- Aristotle: Rhetoric; Poetics.
- Quintilian: selections from Institutio Oratoria.
- On the Sublime, traditionally attributed to Longinus.
- Horace: Ars Poetica.
Content: forensic, deliberative and ceremonial speech; argument; credibility; emotion; arrangement; style; education; literary judgement.
Practice: analyse an actual speech; compare rhetorical theory and practice; write or deliver a short speech and explain its choices; close-read a passage using a critic’s categories without treating them as universal rules.
Existing connections: thucydides, socrates, rhetoric, cicero and shakespeare.
To be specified: exact Greek speeches, Quintilian selections and written/performance assessment.

F10. GREEK HISTORY AND HISTORIOGRAPHY
Historical coverage: Bronze Age societies; early Iron Age and archaic Greece; emergence of the polis; colonisation; Persia and the Greek world; classical Athens and Sparta; the Peloponnesian War; fourth-century developments; Philip II; Alexander; Hellenistic kingdoms.
Selected primary authors: Herodotus; Thucydides; Xenophon; Arrian; Polybius.
Additional evidence: inscriptions, archaeology and other material evidence, selected for each period.
Purpose: provide continuity and chronology while teaching how historical claims are made from surviving sources.
Skills: dating; geography; comparing accounts; recognising authorial purpose; distinguishing event date from source date; weighing literary and material evidence.
Existing connections: herodotus, thucydides, alexander and the Yale course.
A source written under the Roman empire can still be central to studying earlier Greek history. Store author, composition context and historical subject separately.
To be specified: a modern survey spine, exact Xenophon and additional source selections, maps and thematic modules.

F11. ROMAN HISTORY AND HISTORIOGRAPHY
Historical coverage: early Italy and Rome; republican institutions; Mediterranean expansion; civil conflict; the transition to the principate; imperial government; provincial worlds; the later empire and late antiquity.
Selected primary authors/texts: Livy; Polybius; Sallust; Caesar; Cicero’s letters; Augustus’ Res Gestae; Tacitus; Suetonius; Ammianus.
Additional evidence: inscriptions, coins, archaeology, documentary records and legal material as appropriate.
Skills: comparison of literary genres; imperial self-presentation; republican political argument; source hostility and bias; institutional change; changing geographical perspectives.
Existing connections: alexander, republic-history, cicero, aeneid, empire and augustine.
To be specified: modern survey spine, sources for later imperial history, precise letter/book selections, chronology and historical geography resources.

F12. RELIGION AND MYTHOLOGY
Coverage: Greek and Roman cult, ritual, sacrifice, festivals, divination, household religion, mystery cults, Judaism in the ancient Mediterranean and early Christianity.
Selected literary sources: Homeric Hymns; Hesiod; Euripides; Ovid; Apuleius; selected Jewish and Christian writings.
Other sources: religious inscriptions, ritual calendars, sanctuaries and relevant archaeological evidence.
Purpose: distinguish mythic narrative, ritual practice, philosophical interpretation and changing religious institutions. Avoid treating religion as a glossary of gods.
Practice: compare different tellings of a myth; reconstruct a festival from evidence; assess how a sacred place or religious object was used; distinguish normative texts from observed practice.
Existing connections: hesiod, tragedy, comedy, ovid, augustine and the Oxford Greek Mythology course.
To be specified: individual hymns, Jewish and Christian texts, documentary evidence packs and specialist options.

F13. SOCIETY, INSTITUTIONS AND LAW
Coverage: citizenship, slavery, gender, households, education, sexuality, migration, work, trade, social hierarchy and government.
Sources: court speeches, contracts, letters, epitaphs, documentary records and legal excerpts, including selections from Gaius’ Institutes, with modern scholarship.
Purpose: place authors in social worlds and expose the limits of relying exclusively on elite literary voices.
Skills: distinguish legal status from lived practice; identify whose perspective survives; compare prescriptions with evidence; consider variation between periods and places.
Practice: study a dossier on a household, legal dispute, worker, migrant or enslaved person, making the limits of the evidence explicit.
Existing connections: themes appear in many V1 modules, but there is no dedicated, coherent strand yet.
To be specified: source dossiers, precise legal excerpts, thematic sequence and supporting readings.

F14. ART, ARCHAEOLOGY AND MATERIAL CULTURE
Coverage: architecture, sculpture, pottery, painting, urban space, domestic buildings, burial and landscapes.
Anchor case studies proposed: Athenian Acropolis; Olympia; Pompeii; Ostia; Roman Britain.
Purpose: learn to interpret ancient objects, buildings and spaces as evidence in their own right, alongside texts.
Skills: observation; description; dating; material and technique; archaeological context; function; provenance; interpretation; recognition of uncertainty.
Practice: object commentary, site comparison, an annotated plan, or a museum-based evidence exercise. Fieldwork or museum activities need realistic access options and should not be falsely represented as completed online.
Existing connections: no dedicated V1 modules; this is a major addition.
To be specified: selected objects, rights-cleared imagery, museum/source links, site plans, modern readings and access alternatives.

F15. HOW CLASSICAL SCHOLARSHIP WORKS
Coverage: source criticism, translation comparison, textual transmission, manuscripts, critical editions, metre and introductory historical linguistics.
Evidence specialisms: epigraphy (inscriptions), papyrology (papyri), numismatics (coins), with optional deeper routes.
Purpose: teach how ancient texts and objects become the evidence encountered in books and databases.
Skills: locate a passage across editions; understand common citation systems; identify a textual variant; distinguish authorial words from editorial restoration; read basic apparatus conventions after preparation; evaluate scholarly argument and bibliography.
Practice: compare translations and explain a consequential difference; inspect a small manuscript/printed-text comparison; assess an inscription or coin using an evidence worksheet; write an annotated bibliography.
Existing connections: scattered translation and source-critical exercises exist, but systematic training is proposed.
To be specified: introductory texts, accessible evidence examples, language prerequisites and specialist depth. Do not require mastery of every technical field to finish the common core.

F16. CLASSICAL RECEPTION
Coverage: reception within antiquity; Byzantine preservation and scholarship; Arabic philosophical transmission; medieval Latin culture; Renaissance humanism; later and modern reinterpretations.
Selected literary catalogue: Dante; Chaucer; Shakespeare; Milton; selected Montaigne; Aimé Césaire; Derek Walcott.
Already assigned in V1: selected Divine Comedy; Julius Caesar and related readings; Paradise Lost; Omeros.
Not yet assigned: exact Chaucer, Montaigne and Césaire works and passages, plus sources for Byzantine, Arabic and other transmission topics.
Additional media: visual art, theatre, film and political uses of antiquity.
Purpose: show transmission, adaptation, disagreement and reinvention across cultures. Later works are independent achievements, not merely copies or illustrations of ancient texts.
Skills: identify actual channels of transmission; distinguish direct reading from mediated influence; compare changes in audience and context; avoid forcing every later character into an ancient equivalent.
Practice: a comparative project connecting an ancient work with a later text, performance or image, including what is changed or resisted.
To be specified: the additional texts and media examples, explicit links between them, and the exact boundaries of specialist reception routes.

F17. OPTIONAL ANCIENT SCIENCE AND MEDICINE
This is an optional catalogue strand rather than a requirement to study every listed author.
Proposed selections: Hippocratic writings; Aristotle’s biological works; Euclid; Archimedes; Ptolemy; Galen.
Purpose: include ancient reasoning about nature, bodies, mathematics, explanation and knowledge.
Practice: analyse a selected argument, observation or proof in its historical context, and compare its evidential standards with another ancient approach.
Relevant links: philosophy of nature, logic, history of knowledge and textual transmission.
To be specified: the actual treatises/passages, mathematical prerequisites where applicable, translation choices and workload. No claims about a learner’s ability to use ancient medicine as modern medical guidance belong in the app.


G. DETAILED PHILOSOPHY SEQUENCE [PROPOSED V2]

This expands F7. These are recommended selections and directions for scope, not a completed schedule for every book listed.

G1. Early thought and fragmentary evidence
Authors: Heraclitus, Parmenides, Democritus, situated within a wider introductory account of early Greek philosophy.
Questions: What is change? What counts as knowledge? What is reality made of? What survives of the original argument?
Skills: distinguish fragments from later testimony; compare interpretations without inventing missing context.
Scope: selected fragments/testimonia with an annotated scholarly guide; exact selection to be specified.

G2. Socratic inquiry
Primary texts: Plato’s Euthyphro, Apology, Crito and Meno.
Questions: What is a good definition? What is virtue? Can it be taught? What obligations does a citizen have?
Skills: reconstruct an argument, identify assumptions, formulate objections and separate dramatic context from a simple doctrine summary.
Existing overlap: socrates covers Euthyphro, Apology and Crito at different depths; Meno is an addition.

G3. Plato in depth
Primary texts: Phaedo, Symposium and Republic, followed by selected Theaetetus and Timaeus.
Coverage: soul, love, justice, education, political authority, knowledge and cosmology.
Scope: complete central dialogues where suitable for an extended route; clearly assigned excerpts for the most technical additions. The exact new assignments remain to be set.
Existing overlap: republic and the partial Phaedo assignment in socrates.

G4. Aristotle in depth
Primary texts: Nicomachean Ethics, Politics and Poetics, plus selected Categories, Physics, On the Soul and Metaphysics.
Coverage: flourishing, virtue, citizenship, logic and classification, change and explanation, mind/soul, being and artistic representation.
Skills: handle technical vocabulary, distinguish kinds of question and reconstruct arguments with careful references.
Do not make a single reading of Aristotle a prerequisite for all philosophical study. Use passage-specific dependencies and prepare terminology before difficult selections.
Existing overlap: aristotle and rhetoric. The wider logic, nature, mind and metaphysics work is new.

G5. Hellenistic and Roman schools
Primary texts/authors: Epicurus’ letters and doctrines; Lucretius; Cicero’s philosophical works; Seneca; Epictetus; Marcus Aurelius; selected Sextus Empiricus.
Coverage: Epicureanism, Stoicism, scepticism, competing accounts of knowledge and the philosophical life.
Skills: compare schools using arguments rather than stereotypes or isolated quotations; distinguish literary form and authorial context.
Existing overlap: hellenistic, stoics and cicero. Sextus and the broader comparative treatment are additions.

G6. Late antiquity and the medieval bridge
Primary texts/authors: selected Plotinus; Augustine’s Confessions and appropriate related material; Boethius’ Consolation of Philosophy.
Coverage: transformations of Platonism, inwardness, time, providence, freedom and the transmission of philosophical traditions.
Existing overlap: augustine. Plotinus and Boethius need new assignments.

G7. Philosophy discovery filters [HANDOFF RECOMMENDATION]
Subfield tags: ethics; politics; epistemology; metaphysics; logic; nature; mind/soul; aesthetics; philosophy of religion where relevant.
School/tradition tags can supplement, not replace, dates and author metadata.
Keep a primary philosophical text distinct from a modern explanation, a commentary and the learner’s own essay.


H. LANGUAGE PROGRESSION AND READING STRATEGY [PROPOSED V2 + HANDOFF RECOMMENDATION]

H1. Language routes
Offer four independent language choices: translations; Latin; Greek; both languages.
The translation route must remain usable and intellectually serious. The language routes add explicit skills, exercises, authentic-text milestones and extra study time.
A learner may study philosophy or history rigorously in translation while remaining a beginner in Latin or Greek. Language level and academic depth are different dimensions.

H2. Suggested progression within each language
- Orientation: script where applicable, sound system, basic grammatical terminology and an introduction to how the language works.
- Foundations: morphology, syntax, vocabulary and short adapted passages, with frequent review.
- Guided authentic reading: carefully selected prose or short verse, with notes and linguistic help.
- Developing independence: longer passages, prepared and appropriately graded unprepared translation, commentary and reduced reliance on aids.
- Genre-specific extension: poetic language, metre, dialect or an author’s prose style; specialist textual work if chosen.
These are design stages, not automatically awarded proficiency levels. Passing from one to the next needs explicit evidence of reading skill and suitable feedback.

H3. Main textbook decisions
No definitive Greek or Latin textbook was chosen in the proposal. Do not silently treat an OpenLearn taster as the main course. The eventual main textbook, exercise bank and feedback arrangement must be selected and labelled as a new editorial decision.

H4. Broad reading versus close study
Retain a smaller set of central works for substantial or complete reading: the Homeric epics, selected plays, Republic, Aeneid and a major prose narrative such as The Golden Ass were identified as central choices.
For large corpora—historians, letters, fragmentary poetry, technical philosophy and law—start with carefully designed selections. Extended and specialist paths can expand them.
Existing rigorous assignments remain the exact V1 assignments until deliberately revised. For example, the initial Aeneid and Metamorphoses rigorous paths already specify complete readings, while other large works use selections.
Do not mark an entire work as completed when only an excerpt assignment was completed.

H5. Parallel strands
History, language and methods should run alongside literary reading. A learner should not have to finish an enormous history course before reading a play.
Illustrative module connection: Antigone can combine the complete play, Athenian institutions, theatrical performance, burial customs, translation comparison and a reasoned argument about law.
This is a proposed integrated design example, not a claim that every supporting pack has already been prepared.

H6. Historical and textual distinctions
Record composition context separately from represented events. Record original language separately from an author’s geographical/cultural context and the language used by the learner.
Do not assign modern nationalities to ancient authors as if modern states and ancient identities aligned neatly.
Greek-language literature under Roman rule should remain discoverable as both Greek-language literature and Roman-period culture. Works crossing several traditions should retain multiple relevant tags.
Preserve ancient forms and modern reception categories. Lucretius is poetry and philosophy; a letter may be philosophical and literary; a dialogue is not simply a modern essay.


I. PROPOSED APP ARCHITECTURE AND LEARNING DESIGN [PROPOSED V2]

I1. Three independent controls
Coverage:
- Common core: selected modules providing breadth across the principal components.
- Extended survey: fuller reading and additional authors/periods.
- Specialist options: deeper work in chosen areas.

Study depth:
- Reading and reflection.
- Close study with scholarship.
- Assessed work.

Language route:
- Translations.
- Latin.
- Greek.
- Both languages.

Do not present the new three-axis model as already implemented. V1 has only Lighter/Rigorous over the same 24 translation modules.

I2. What “assessed work” means
Every substantial module should offer an appropriate piece of work: close commentary, philosophical argument, source comparison, object analysis, translation, oral presentation or research essay.
An assigned essay is not automatically externally assessed. If a route promises marking or feedback, it must identify the actual arrangement. Otherwise label it as a self-assessment exercise with criteria. Do not imply university credit or instructor review where neither exists.

I3. Proposed module contents
For each developed module, provide:
- A rationale and concrete learning outcomes.
- Primary text or evidence assignments with explicit scope.
- Historical/cultural context.
- Selected modern scholarship or commentary.
- A named skill to practise.
- Preparation: distinguish helpful reading from genuine language/technical requirements.
- Study questions.
- An activity or assessment matched to depth.
- Reading resources and source URLs, including access type and verification date.
- Estimated time, with its basis and exclusions.
- Links to related modules and later reception.
- Notes and a progress state tied to that exact assignment version.
This is a handoff specification, not a claim that those fields are populated for all proposed new modules.

I4. Additional discovery controls [HANDOFF RECOMMENDATION]
Retain period, subject, progress and search. Add useful filters when corresponding metadata is available: form/genre, original language, language requirement, author, coverage tier, study depth, skill and time estimate.
Genre vocabulary should cover at least epic, didactic poetry, lyric, elegy, pastoral, satire, epigram, tragedy, comedy, prose fiction, dialogue, biography, historiography, speech, letter, treatise, reflective essay and documentary evidence. Allow multiple tags and clarify ambiguous modern labels.
Material evidence should be searchable by evidence type rather than being forced into the “book” category.

I5. Reading order and dependencies
Keep both a chronological overview and a pedagogical reading route. They serve different purposes and must be labelled.
Permit branching: reading order is a guide, not a requirement to finish every previous item before exploring a new subject.
Soft dependencies: useful preparatory readings.
Hard prerequisites, only where warranted: language level, a technical skill or a specific prior assessed outcome.
Dependencies must form a coherent acyclic graph. No broken references or circular requirements.
The expanded programme must not make all technical specialisms compulsory. Broad introductory awareness and specialist mastery are different goals.

I6. Modern scholarship
Use a manageable supporting spine: historical surveys, annotated editions, introductions, scholarly chapters and selected articles linked to primary evidence.
No complete modern secondary bibliography was selected in the conversation. It must be researched and assigned before claiming the expanded programme is fully specified.
An app should distinguish primary texts, translations, commentaries, modern scholarship, lectures, course descriptions and the learner’s own work.

I7. Organised courses
Keep a separate directory. Each entry should identify provider, course title, delivery mode, language/entry requirements, time commitment, access/cost type, dates where verified, feedback/assessment provision, exact source URL, last check date and its relationship to syllabus modules.
Distinguish recorded lectures, independent courses, scheduled tutor-led short courses and formal programmes.
Prioritise tutor-led language teaching and meaningful feedback on written work when expanding the directory.
The only concrete course entries already selected and included are the four in Section D. Do not create fictional enrolments, tutors, fees, dates or current availability.
Course participation and syllabus completion remain separate. A course can support several modules without automatically completing any of them.

I8. Workload and study planning
New material requires fresh estimates. Separate primary reading, secondary reading, language exercises, writing, tutorials and optional field/museum activity where useful.
Do not double-count shared readings across cross-listed modules without explanation.
Do not reuse the initial 178/604-hour totals for V2. No total hours, qualification equivalence or guaranteed completion time was established for the expanded programme.
A future personalised plan can combine parallel language and content strands, but it should state its time assumptions.

I9. Progress and export [HANDOFF RECOMMENDATION]
Preserve notes and completion for existing modules. Provide progress per assignment and route, not a single “all Classics completed” tick.
Distinguish module completion, work/selection completion and skill achievement. They are not interchangeable.
Retain a full TXT export. A later structured export/import and durable account-based storage would improve portability, but neither exists in V1. Any persistence changes should preserve the owner-only privacy requirement and allow migration of local data.

I10. Course and source availability
Store course-check dates independently of document-generation dates. Never refresh a verification date without checking the source.
Show known access limitations: older translation, index/catalogue link, subscription, purchase, library access, archive or provider enrolment.
Broken links should not erase the reading assignment: the assigned text can still be obtained in another suitable edition.

prompt = study question.
exercise = rigorous written/practical task.
refs = resource IDs in Section E.
language = original-language/reading-language description.
The uniform lighter task is specified in each record. It is generated by the interface rather than stored separately in the existing data array.

J2. Recommended expanded entities
Work: stable ID; canonical title; alternate titles; author/tradition; original language; form/genre; composition context; represented period; survival status; editions and translations.
Module: stable ID; status; title; description; subject/skill tags; outcomes; pedagogical position; prerequisite relations; links to work/evidence records; route eligibility.
Assignment: stable ID and revision; module; depth; language route; exact scope; primary/secondary classification; activity; estimate; evidence of completion.
Resource: stable ID; type; title; provider/author; URL; access conditions; verification date; known limitations.
Course: provider-defined educational offering, linked to modules without being merged into them.
Learning state: the user’s assignment completions, notes and separately evidenced skills.
Evidence item: an inscription, papyrus, coin, object, image, building or site with provenance/context, source reference and appropriate rights information.
Do not store a whole author corpus, a whole work and a small passage as though they were the same learning unit.

J3. Migration from V1
Retain the 24 existing IDs in Section C. If modules are split, preserve a mapping from each old ID and assignment to new records.
Preserve V1 completion separately for its Lighter and Rigorous assignments. Neither implies completion of new V2 reading or language skills.
Shared notes stay attached to the relevant original module or are copied through an explicit mapping. Do not erase them when changing taxonomy.
Do not seed the user’s reading history from recommendations, summaries or prior questions.
If course/provider metadata changes, preserve relevant version/check-date information.
A source change that materially enlarges an assignment should create a revised assignment rather than silently reinterpreting an earlier completion.

J4. Import priorities
1. Import the implemented V1 records faithfully as the introductory route.
2. Import the proposed components as planned catalogue areas, with status PROPOSED_V2.
3. Keep the “to be specified” items visible to editors. Do not replace them with fabricated data.
4. Add the three independent route controls only when the necessary assignment metadata exists.
5. Develop missing language, historical-survey, material-culture and methods modules into complete assignments before labelling those routes finished.
6. Preserve private access. Do not broaden visibility without explicit user approval.

J5. Suggested acceptance criteria for an expanded implementation
- Every current module, stage, course and resource can be recovered from the import.
- All 24 original IDs remain valid or have explicit migration mappings.
- Proposed and implemented content are distinguishable.
- Every assigned reading has a clear scope and a language/edition context where needed.
- Subject and genre filters handle multi-category works correctly.
- Composition dates and historical subject dates are not silently conflated.
- Dependencies have no missing targets or cycles, and soft recommendations remain explorable.
- Selecting a different depth changes the actual assignment, activity and estimate.
- Language advancement is not inferred merely from reading in translation.
- Course entries remain separate from self-study; new availability claims have dated evidence.
- Estimates exclude or separately count external courses and sustained language work.
- Existing progress and notes survive migration.
- An excerpt completion never silently marks an entire work as read.
- TXT export contains all active content, source links and user-owned notes included by the user’s export action.
- Keyboard, mobile, dialog, filter, persistence and export behaviour are tested in real browsers before claiming end-to-end validation.
- Owner-only access is checked before and after any deployment. A noindex tag is not accepted as privacy enforcement.

J6. How to use this handoff as an AI/app-builder instruction
Use this document as the content and product specification for a private Classics syllabus explorer. Preserve the implemented introductory route and the exact reading scopes. Represent the expanded curriculum as proposed until each assignment is developed. Organise the catalogue by subject, form, period, original language, difficulty and skills without flattening cross-cultural or chronological distinctions. Keep organised courses separate. Maintain stable IDs and existing user data. Do not invent missing passage assignments, scholarly sources, course availability, completed learning or degree equivalence. Request explicit approval before broadening access beyond the owner.
